# Risk Explorer Map

Смотри, у нас есть система управления операционными рисками (скриншот этой системы я тебе прикрепила), в этой системе есть раздел, который так и называется "риски". В этом разделе указаны все риски компании в виде списка состоящего из карточек рисков (каждую из которых можно открыть и посмотреть всю информацию о риске). В этом разделе есть быстрые фильтры (тогглы) по типам рисков (активные, архивные, в работе). У рисков есть виды (репутационные, политические и тд) и теперь из-за того что рисков достаточно много хочется иметь какую-то карту рисков. Тебе нужно будет именно ее и добавить отдельным тогглом в верхней части (в ряд с активные риски/анализ рисков и тд). Возьми максимально близкий дизайн и цвета и минималистичный стиль, вот требования к самой карте рисков: Карта рисков должна быть реализована в разделе риски как альтернативное представление данных наряду со списком карточек рисков, переключение между списком и картой осуществляется пользователем. Карта отображает элементы по каждому виду риска из справочника видов, для каждого вида риска на карте выводится один элемент, размер этого элемента визуально зависит от суммы выбранного показателя: чем больше сумма, тем больше площадь элемента, при этом минимальный размер элемента должен быть достаточным для отображения названия вида риска и числового значения или прочерка, чтобы даже самые малые суммы и категории без данных были видны и различимы. На элементе обязательно отображается название вида риска и одна цифра, соответствующая сумме выбранного пользователем показателя, либо прочерк, если по данному виду риска и выбранному типу отсутствуют данные, то есть нет ни одного риска данного вида с учетом выбранного быстрого фильтра. Если по виду риска есть риски, но сумма выбранного показателя равна нулю, отображается цифра ноль и минимальный размер элемента. Пользователь может выбрать какой показатель агрегировать через переключатель из трех вариантов: факт потерь, лимит, прогноз, при изменении выбранного показателя карта пересчитывается и размеры элементов и цифры обновляются. Элементы карты не должны перекрываться и должны быть расположены так, чтобы все виды рисков были одновременно видны без прокрутки, допускается сеточное или мозаичное расположение элементов с автоматическим подбором размеров в зависимости от суммы, но не круговая диаграмма и не сектора. Карта учитывает текущий быстрый фильтр по типу риска, который выбран в разделе: если выбран фильтр активные, то суммы на карте считаются только по активным рискам, если архивные то по архивным, если в работе то по рискам в работе, при переключении быстрого фильтра карта автоматически обновляется. При клике на элемент карты происходит переход к представлению списка рисков, при этом к текущим примененным фильтрам раздела добавляется фильтр по виду риска, соответствующему кликнутому элементу, быстрый фильтр по типу сохраняется, пользователь видит список карточек рисков только выбранного вида и выбранного типа, все остальные ранее установленные фильтры остаются активными, даже если на элементе был прочерк, переход осуществляется и список может быть пустым.
